# Phase 11A 收尾执行计划

2026-09-11，用户授权继续。沿用 DEV-PLAN Phase 11A 及已确认的尺寸例外；不修改用户现有任务、模板、Skill 或归档。

1. 只读提取已上传业务包与实际素材，建立独立 PostgreSQL/Redis/MinIO、非 root WSL Worker 与执行目录。验收：无共享业务数据写入、任务来源 cli，清理仅作用于本轮资源。
2. 两图串行闭环：首次生成、单图返工、归档、重启、整套返工。验收：同 session、新 PID、单图不改非目标、旧版本及归档字节不变、下载图片可解码、ZIP 包内容一致；记录真实播报与耗时。
3. 独立配置并发2，双任务同时执行；同任务争用与消息重投。验收：真实PID区间重叠，各任务不同session/目录、只执行一次、图片归属正确，采样CPU/内存/usage；结束恢复1。
4. 隔离环境验证取消/超时与Worker失联保护，结合现有真实取消证据及受控故障集成测试，明确区分真实CLI与受控执行器证据；不得将未知轮次自动再生成。
5. 更新阶段验收记录，执行必要回归、构建、浏览器验证与独立两阶段审查。商品/文字Skill未提供仍留Phase14，不虚报通过。

测试入口须显式指定运行真实CLI，不进入普通单元测试，不记录凭证或完整原始模型日志。用户当前开发服务保持并发1，专用环境测试结束删除临时库、容器及执行空间，报告与必要结果另存忽略目录。

独立审查后的补强：每轮恰有一个具备 PID/出生身份/CLI 版本的 attempt，恢复前后身份一致；取消/超时截止后必须同时确认 attempt、round、job 终态，超时耗时符合设定容差；进程托管覆盖父进程在首次采样前退出的孤儿窗口。补反例测试及无模型环境复验，不为验证辅助脚本重复支付已通过的生图轮次。
