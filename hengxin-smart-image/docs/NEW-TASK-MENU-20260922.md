# 图片处理菜单新建修复 · 2026-09-22

## 问题与修复

图片处理菜单此前重复跳转同一路径，创建会话按用户、模式和查询参数缓存，导致再次进入时复用上一单的已受理回执。现在三个图片处理菜单每次携带新的 `newTask` 标识，进入独立空白表单，同页重复点击也生效。既有任务继续运行并在任务中心查看；原提交会话及幂等键保持不变，不自动重放未知请求。

业务变更仅 `frontend/src/utils/navigation/jump.ts`，不改变提交API、Worker或数据库。需求及开发计划已同步。
