# 钉钉双端登录配置清单

本清单对应 DEV-PLAN Phase 12.2。钉钉配置由企业管理员在开放平台完成，代码和 VPS 部署由开发侧完成。不要把 AppSecret、访问令牌或授权码提交到 Git、粘贴到聊天或填入前端页面。

## 需要准备的资料

| 项目 | 用途 | 是否可提供给开发侧 |
| --- | --- | --- |
| 企业 CorpId | 校验登录成员所属企业、PC 容器免登参数 | 可以提供 |
| 企业内部 H5 应用 Client ID/AppKey | 浏览器授权和 PC 容器免登 | 可以提供 |
| AgentId | 企业内部微应用标识及发布配置 | 可以提供 |
| AppSecret/Client Secret | 服务端交换授权码和获取成员身份 | 只写入 VPS 环境 |
| 应用可见范围 | 限制哪些企业成员能打开应用 | 可以提供范围截图或成员名单 |
| 通讯录个人/成员信息读取权限 | 获取成员身份和部门信息 | 需要企业管理员申请 |
| HTTPS 首页域名 | 钉钉应用首页和浏览器登录来源 | 可以提供 |
| HTTPS 回调地址 | 浏览器授权完成后的服务端回调 | 可以配置 |
| 初始超级管理员成员标识 | 首次登录后绑定系统超级管理员，可配置多个 | 可以提供多个 userId；不要用姓名猜测 |

## 开放平台配置

本次联调域名为 `zhitu.qhhengxin.top`。

创建或选择“企业内部开发”的 H5 微应用，配置：

1. 应用首页地址：`https://zhitu.qhhengxin.top/`
2. PC 端首页地址：`https://zhitu.qhhengxin.top/`
3. 网页授权回调地址：`https://zhitu.qhhengxin.top/api/v1/auth/dingtalk/callback`
4. 可见范围：先加入本次联调的管理员、主管、设计和运营测试成员。
5. 权限：申请通讯录个人信息读取和成员信息读取所需的最小权限；按姓名解析成员 userId 时才需要开通 `qyapi_addresslist_search`（通讯录用户搜索）。钉钉控制台的权限名称可能随版本变化，以当前控制台显示为准。
6. 发布或允许测试版本，否则成员在工作台中看不到应用。

## 提供方式

可以先把下面四项以普通文本发给开发侧：

```text
CorpId=
Client ID/AppKey=
AgentId=
首页域名=https://zhitu.qhhengxin.top/
初始管理员 userId=吴永杰对应的userId,张帅对应的userId
```

AppSecret/Client Secret 请在 VPS 上写入部署环境，例如 `/opt/hengxin-smart-image/infra/.env`，不要粘贴到聊天。初始管理员的钉钉 `userId` 用英文逗号分隔写入 `DINGTALK_ADMIN_USER_IDS`，姓名只用于核对，不能替代 userId。

## 当前环境限制

2026-09-16 已确认 VPS 的 HTTPS 入口为 `https://zhitu.qhhengxin.top/`，钉钉配置接口可用。已将 VPS 的 `ENABLE_DEV_IDENTITY` 关闭并重建 API，无会话访问 `/api/v1/auth/me` 返回 401。真实登录测试使用此域名；禁止开启开发身份来代替钉钉验收。

2026-09-16 较早一次检查时，本地 3008 连接旧开发 API，钉钉配置接口返回 404；这是当时的运行实例状态，不代表当前源码。新机器需自行核对，真实验收使用 VPS HTTPS。开发身份仅供本机联调使用。

钉钉 PC 容器使用 `requestAuthCode` 获取一次性临时授权码；普通浏览器使用官方 OAuth2 授权跳转。两种入口最终都由后端验证企业成员并签发系统会话。官方 JSAPI 当前文档说明 `requestAuthCode` 的参数包含 Client ID 和 CorpId，并支持 Windows/Mac 钉钉 PC；官方 H5 免登示例采用服务端用授权码换取用户身份的链路。

## 验收用测试成员

至少准备以下成员：

- 2 名超级管理员：分别绑定 `super_admin`，验证多人初始管理员配置。
- 1 名设计主管：验证全员统计和主管权限。
- 1 名设计人员、1 名运营人员：验证两角色同权限集合。
- 1 名可见但未分配系统角色的成员：验证待授权。
- 1 个被禁用的系统账号：验证会话和业务请求被拒绝。

验收时覆盖 Chrome/Edge 普通浏览器和钉钉 Windows PC 容器：首次登录、再次访问、授权拒绝、state 重放、过期重登、待授权、禁用、上传、异步任务、下载、返工和归档。
