# Skill轻量目录管理

本轮替代管理员手动登记版本、检查再启用的流程；既有版本数据只用于历史兼容和内部执行快照。实现与验收见 `LIGHT-SKILLS-VALIDATION.md`；已部署生产，发布状态与回滚边界见 `LIGHT-SKILLS-DEPLOYMENT.md`。

## 管理员操作

1. 在配置的Skill根目录放置 `<Skill标识>/SKILL.md` 及其完整配套文件。管理员负责文件和依赖维护，Worker只读；不要放软链接、硬链接或特殊文件。
2. 在Skill管理点击“同步 Skill”。平台读取名称和功能描述、检查目录及隔离环境依赖，保存完整执行快照；不运行Skill内脚本，不发起生图。
3. 未声明且没有历史记录可确定处理类型时，在列表选择壁纸/商品/文字后同步。不要用描述中的关键词猜分类。新技能通过后直接可用，手动停用的技能不会因同步重新启用。
4. 选择默认Skill，或在模板中指定Skill。以后更新文件仍只需要同步，不填写版本号。列表描述可以展开全文，模板选择也显示用途。

说明来自SKILL.md的YAML `description`，以文件为单一来源；网页不另设一份易失步的描述。描述可以包含输入数量、图片尺寸、修改范围、输出格式和适用场景。名称与实际目录标识一致。

## 内容更新与任务

- 同步成功后，新任务使用该Skill的最新成功内容。模板与默认配置绑定稳定Skill身份，不需要逐模板切版本。
- 已提交、排队、执行中的任务和之后的返工，使用提交时固定的完整内容；管理员覆盖目录不应影响已保存的新执行快照。
- 同步异常、目录缺失或快照保存失败必须可见，不把旧快照伪装成本次同步成功；新任务不可静默切到别的Skill。
- 旧目录和ZIP绑定继续兼容；不自动删除老发布目录。升级前旧本地任务仍需保留其原发布树，直到相应历史内容完成快照转换或不再需要返工。
- 移除登记不删除服务器文件及历史任务快照。模板或默认绑定仍引用时先解除；仅历史任务引用不应阻止新目录登记的移除。目录仍存在时，下次同步可以重新发现。

## 验收范围

覆盖目录发现、重复同步、异步状态、类型选择、描述全文、启停保持、默认/模板跟随、历史任务不漂移、内容真实字节、异常与安全边界、迁移兼容和移除保护。真实模型视觉效果与同步校验是不同验收项。
