# 国内 AI 工作台独立交互预览

用户确认方向：国内菜单点击直接进入 AI 工作台；新品生成下为「相机配件生成」「手机壳生成」；产品替换下为「只换产品」「换场景 / 模特 / 产品 / 修改尺寸」「换手机 / 壁纸 / 膜」。五个入口共用工作台结构，但拥有独立的对话、草稿、附件和教程。没有任务创建、审批及新增记录页面；独立一级菜单「成品库」，只接收新品生成的归档。默认只展示对话和输入；对话切换与素材按需展开，普通用户不选择 Skill。

复用现有 Art 侧栏、顶栏、页签、布局、Element Plus 与项目样式。虽然共享外壳组件文件名为 OverseasShell，其内部就是国内外共用的 Art 布局，不使用海外业务流程或接口。

启动：在 frontend 目录运行 `node node_modules/vite/bin/vite.js --config preview-domestic-studio/vite.config.ts --mode demo`。

入口：http://127.0.0.1:3025/preview-domestic-studio/index.html#/new-product/camera-accessories

检查范围：五个二级菜单直接进入；教程示例填入但不自动发送；附件选择、拖入、粘贴与移除；模拟发送/停止/连续对话；新建及切换对话、草稿隔离；素材预览和引用；展开编辑与工作台；390px 窄屏。

界限：独立本地预览，不调用业务或模型 API，不安装或绑定实际 Skill。发送仅返回明确标注的演示文字，不伪造生成图片。图片标注和真实输出区待接入阶段复用已有组件。本地附件仅保留于当前页面内存，刷新清空。没有修改正式需求、设计规范或生产路由。

教程预览：五个入口均有顶部『使用教程』入口；工作台空会话中间留白，不显示欢迎、上传卡片和示例区。桌面宽度≥1450px时右侧并排展开；窄屏用抽屉。图文指南含示例步骤、素材用途示意、复制及追加示例；综合入口含分类提示，视频页明确待补充。教程打开状态可随入口切换，内容按业务变化，不自动发送或覆盖草稿。教程为示例内容，未作为正式使用文档。

多会话预览：每个业务入口独立维护最多10个会话（沿用海外交互）；桌面左侧默认展开，单条菜单支持重命名/删除，顶部和列表均可新建，允许多个空白会话。会话显示当前选中、演示处理中、有草稿等状态。每个会话独立模拟执行，切换及新建不停止其他会话；处理中删除禁用。删除弹窗明确对象，确认后只清理该会话本地资源，保留其他会话和当前选择；删除最后一条后新建空白会话。教程可与会话栏并排展示，较窄窗口使用抽屉。仍为内存演示，刷新清空；不代表真实服务端会话、生成、持久化或删除已接入。

成品库预览（本轮）：「成品库」作为独立一级菜单，排在「产品替换」之后，直接进入列表；相机配件生成、手机壳生成的当前会话栏提供「归档到成品库」，产品替换三个工作台无归档入口。空会话和回复处理中禁止归档，完成演示回复后只填产品名称即可保存独立对话/已发送附件快照；草稿和未发送附件不归档，附件复制独立 blob URL，删除原会话不破坏归档。成品库支持产品名称搜索、来源筛选、详情、确认删除；重复归档生成独立记录，不覆盖旧档。无模拟成品图，不将上传资料当成成品，详情明确暂无真实成品图片。以上均内存交互预览，刷新清空，不是服务端持久化。

消息排版：对齐海外 StudioTurns，用户消息右对齐浅蓝气泡，Codex 回复左对齐。每条消息记录发送人姓名快照和创建时间，统一复用北京时间格式；回复完成/停止时记录各自实际演示时间，执行中不伪造回复时间。归档复用同一消息组件保留姓名时间。预览账号明确为「演示用户」，未接登录认证，不能声称已验证真实用户姓名；正式接入需使用服务端 actor.name/createdAt/replyAt。

Skills 管理预览：管理中心二级菜单，仅超级管理员演示身份可见，并有路由、页面与写操作检查（不代表后端鉴权）。沿用海外逻辑：完整 Skill 文件夹上传、新增默认关闭、同名上传核对差异后更新、启用/停用、统一下载 ZIP（不提供保存为文件夹）、删除。复用海外目录扫描、元数据解析、ZIP 构建模块。没有在线编辑器或版本管理界面。国内差异仅工作台固定绑定：五个入口各绑定一个启用 Skill，普通用户不选择；已绑定的 Skill 需先更换/解绑才可停用或删除。初始五条均标注为示例 Skill，修改仅当前页面内存，刷新重置，未连接真实安装与执行器。
