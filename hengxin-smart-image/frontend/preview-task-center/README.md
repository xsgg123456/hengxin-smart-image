# 任务与管理员任务中心独立预览

仅用于确认交互，不接生产、不调用AI、不修改正式路由/组件/需求文档。复用现有 Art 外壳、主题、Element Plus、业务菜单名称及基础样式。

从 frontend 运行 `node node_modules/vite/bin/vite.js --config preview-task-center/vite.config.ts --mode demo`，打开 http://127.0.0.1:3038/preview-task-center/index.html#/new-product/camera-accessories 。

## 当前交互

- 顶部可切换设计人员、运营人员、超级管理员；身份仅用于演示，保存在本预览 sessionStorage。
- 所有角色的五个业务子菜单只显示自己的对应业务任务，可新建命名任务、进入任务管理多个独立方案会话。
- 任务中心移入管理中心，仅超级管理员可见和进入；原一级任务中心与工作台会话菜单均移除。旧预览地址兼容跳转，但普通角色不能进入管理查看。
- 管理任务中心汇总全部成员任务，支持成员、业务、名称、状态筛选；不提供新建、改名、完成或删除。其下所有详情（包括自己的任务）统一只读，方案切换只改变本地查看选择，不更改任务编辑会话选择。
- 超管需要编辑自己的任务时，从相应业务菜单进入。普通角色切换时移除管理页签并离开管理页面。
- 任务内支持新建、切换、改名、删除方案，演示消息和草稿分别保存。任务完成/重开、任务改名/删除仅在自己的业务操作路径提供。

浏览器 localStorage 键 `hx-isolated-task-preview-v1` 保留先前预览任务；只有显式点击并确认重置才恢复示例。附件仅保留文件名，不读取或上传内容。正式任务生命周期、历史数据迁移和服务端权限仍待正式实施。

## 验证

预览vue-tsc通过。浏览器实测设计/运营无管理入口、运营从业务菜单创建并锁定业务、普通直接访问新旧管理地址返回业务列表、超管管理中心无创建/修改按钮、自己的任务在管理详情也只读、他人只读、切换普通身份清理管理页签、超管业务内本人任务仍可编辑。截图在 output/playwright/task-center-{admin,designer}-v2.png。

前版已验证多会话消息/草稿独立、刷新恢复、任务完成/重开及1920/390布局；本轮只改入口与查看范围，未改正式系统。此为非批准性预览审查，不代表生产权限验收。
