任务：只编辑图1中的手机屏幕壁纸及屏内前摄开孔。图2是屏幕内容参考，不是构图参考。保持图1的原始像素宽高、构图及全部非目标内容不变。

【输入】
图1：待编辑的原始电商图片。
图2：手机正面屏幕参考素材。
仅提取图2有效显示区域中的壁纸和前摄开孔，不提取机身、边框、听筒、背景、文字或其他界面元素。
如果另外提供本页屏幕说明，将其作为定位约束；说明文字不出现在输出图中。

【先确定屏幕自身的方向】
逐一识别图1中真实显示壁纸的手机屏幕，区分显示屏、透明保护膜、反射及装饰，不把透明膜或反光误认成第二块显示屏。
对每块屏幕，先判断手机在正常竖直使用时的物理顶部、底部、左侧和右侧，再判断它们在当前画面中的方向。可结合机身结构、听筒及原前摄位置交叉判断；原前摄仅作为方向线索，不决定新前摄的最终位置。
“屏幕顶部”始终指手机自身的物理顶部，不是整张图片的上方，也不是屏幕在画面中外接矩形的上边。横放、倒置、倾斜时，屏幕坐标轴随手机一起转动。
局部屏幕或画面外延伸的屏幕仍属于完整手机屏幕的一部分，不能把当前可见区域当作完整屏幕重新居中。

【统一映射壁纸与前摄】
将图2的有效显示区域视为一张包含壁纸与前摄开孔的完整屏幕贴图。两者不可拆开布局、分别旋转或分别居中。
以图2有效显示区域为坐标基准，左右方向为u轴，手机顶部到底部为v轴。记录开孔在这一坐标系内的位置和大小，而非它在素材整张画布内的位置。
按手机自身方位建立对应关系：参考屏幕的物理左上、右上、右下、左下，分别对应目标屏幕的物理左上、右上、右下、左下；这些点不一定分别位于画布的左上、右上、右下、左下。
壁纸的纹理、走向、所有特征点以及前摄开孔，必须共同经过同一套缩放、旋转和透视映射。不得保持壁纸竖直却只旋转前摄，也不得旋转壁纸后把前摄重新放到画面上方。
先在完整目标屏幕上定位，再由原屏幕边缘、圆角、画布范围和前景遮挡裁出可见部分。禁止把参考整屏压缩到当前可见的局部范围；禁止为了露出镜头移动或缩小整张贴图。
若参考前摄变换后落在画外、被裁掉或被前景遮挡，则按实际可见范围隐藏或部分显示，不得移动到其他可见位置。
开孔的外观与数量来自图2，形状和大小随屏幕透视变化，不得独立放大或校正成面向画布的圆形。新位置由上述统一映射决定，不另行自由生成位置。

【替换与层级】
用映射后的新屏幕内容替换旧壁纸和旧前摄，清除旧孔及其残影，不出现重复开孔。
若新旧开孔的映射位置重合，可在原位置替换外观，不要为了表示“替换”而人为移动镜头。
保留图1原有玻璃、透明膜、膜边、反光、高光、阴影和前景物的形状、位置及遮挡关系，新屏幕内容位于这些效果之下。
透明膜上的白色反光图案不是壁纸，也不是新屏幕，不随贴图旋转或移动。
只处理真实显示壁纸的屏幕；手机背面、纯黑屏、后置摄像头及其他区域保持原样。

【保护范围】
所有文字、字体、字号、排版、图标、背景、商品位置、机身、边框、按键、听筒、后摄和屏幕外效果保持原样。禁止全图重绘、美化、调色、裁切、扩图、缩放画布或改变画布比例。
输出像素宽高与图1一致。禁止将图2的外框、机身或背景带入图1。

【输出前核对】
逐屏检查：物理顶部方向是否正确；壁纸和前摄是否共享同一变换；前摄到对应物理顶边的距离及沿顶边的位置是否符合参考；是否错误地放在画布上方；是否出现原孔残留；裁切和遮挡是否正确；原文字、机身、透明膜和非目标内容是否保持一致。
