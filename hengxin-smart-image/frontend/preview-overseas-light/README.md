# 海外轻量化独立交互预览

范围：用户 2026-11-07 要求基于现有前端一比一预览，供确认交互。不是正式产品需求或上线实现。

1. 复用 OverseasShell、ArtTable、Element Plus、prototype.css 和成品字段组件。原版对照使用真实 Workspace / LiveActivity，改版只在本目录。
2. 调用与执行：合并菜单；按人员统计默认视图，执行次数/图片数/最近调用；共享人员及时间筛选；点击人员看记录；状态栏进入对应执行记录；详情抽屉。
3. 成品库：按曾参与归档的人筛选，可叠加关键词；卡片保留最近归档人与时间，筛选匹配参与人与最近归档人不一致时明确标注；详情展示归档历史。
4. 工作流任务：当前设计负责人列和可搜索筛选；全部/与我相关、状态、关键词组合；默认每页20条，47条示例验证跨页；详情返回保留状态。
5. 只用内存示例；刷新还原；不调用生产 API；不改正式 Spec/Brief/计划/业务代码、不提交、不部署。

本轮追加预览：工作流状态下拉仅「全部状态 / 待处理 / 设计中 / 已完成」，列名改为「任务状态」。待提交、待审核、退回均归待处理并显示一句具体下一步；工作台和旧分析/方案/生成/图片审核归设计中；旧归档和明确完成归已完成。原始状态保留，删除异常独立提示，不加入常用筛选。详情与列表口径一致，切换原版清空状态条件，避免新旧值混用；仍保留人员组合筛选、20条分页和返回状态。

验收：构建与类型检查，1920×911原版/改版对照，1280×800与390×844布局；浏览器验证筛选、下钻、抽屉、分页、返回、空态/加载/错误重试；无业务API请求。

运行：在 frontend 执行 `node node_modules/vite/bin/vite.js --config preview-overseas-light/vite.config.ts --mode demo`，访问 http://127.0.0.1:3037/preview-overseas-light/index.html。
