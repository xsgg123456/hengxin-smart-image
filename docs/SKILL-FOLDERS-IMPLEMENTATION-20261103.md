# 海外 Skill 文件夹管理实施合同

2026-11-03 用户确认完整方案，授权开发、中文 Git 提交及生产部署。覆盖历史海外 Skill 仅离线安装、网页不提供上传与删除的限制。只作用于海外业务。

## 功能与验收

1. 在现有 Skills 管理页面添加上传入口，一次拖入一个完整文件夹，递归扫描全部目录（包括空目录）与文件。扫描时生成相对路径、大小、SHA-256 清单，显示目录树、数量、大小与解析名称描述；用户点击上传安装。超过 100 个同级条目必须全部枚举。任何读取失败、路径冲突或不受支持的读取能力阻止导入，禁止静默丢文件。
2. 原始字节传输；根 SKILL.md 含有效 name/description。名称取正文首个一级标题，无标题时取 name。agents/scripts/references/assets 及其他合法资源完整保存，无改写、无扩展名过滤；明确的包内资源引用缺失拒绝。外部依赖不等于已验证可运行。单文件 64 MiB、整包 256 MiB、1000 文件、2000 文件及目录条目，超限整体拒绝。
3. 暂存、服务器校验、安装副本复核全目录清单与哈希；失败旧目录不变。新增默认关闭、未分配平台。上传状态持久保存、可查询，失败可重试；重复请求幂等，并发发布序列化。上传、更新、删除权限同现有 Skill 开关权限且需 skills.manage；下载需 skills.manage。
4. 同名同内容提示已安装；同名不同内容提供增删改清单，用户明确确认后更新。更新保留平台与开关；新轮使用新包，已提交轮次继续冻结旧版本。
5. 每个 Skill 仅提供“保存为文件夹”，没有 ZIP。由用户选本地父目录，按原目录名新建根文件夹，新上传记录原目录名、历史包用内部 name。完整保存子目录、空目录与原始文件，逐文件读回校验且比对清单后才成功；不增加包内系统文件。目标同名不覆盖；中断明确不完整并支持核验重试；取消目录选择不启动导出。不支持浏览器明确提示。保证结构与内容，不保证本地 ACL/创建时间。
6. 每行删除使用现有二次确认弹窗，显示名称、影响及取消/确认删除。删除后不在当前目录、任何平台或新轮选择；保留历史冻结版本，不破坏排队/在途/重试。二次确认期间版本变动返回冲突。最后一个 Skill 可删除，合法空目录仍正常读取。移出平台与删除 Skill 区分。
7. API 对正式安装目录保持只读；新增专用受控发布服务，输入有界、链接/特殊文件/越界路径拒绝，不执行包内脚本。下载固定已验证发布版本，防更新期间混合内容。发布失败可恢复；记录操作者，保护现有 Skill 字节和业务配置。

## 交付顺序

1. 后端：独立暂存与发布服务、管理 API、完整包校验和下载、空发布与并发/幂等；专项故障测试通过。
2. 前端：拖拽扫描、清单/目录预览、上传进度与更新确认、二次删除、文件夹导出；类型检查、单测、构建通过。
3. 集成：隔离浏览器及 Linux 实际安装路径验证；源目录→上传→导出全量比对；旧冻结版本、权限、并发、删除最后项和故障回归。
4. 独立 code-reviewer 双阶段审查、harness 快照批准、中文提交、制品隐私检查、生产备份/受控部署与正式入口验收。部署不调用付费生图，不删除用户已有 Skill 或真实业务任务。

2026-11-03 发布验证补充：API容器地址切换会使网关缓存旧DNS。发布/回退/切换前恢复均核对固定网关容器身份，配置检查成功后只进行一次平滑重载；在统一总时限内验证公网API readiness及全部依赖为up，公网502不得登记完成。保持网关配置与业务数据不变。

## 页面规范

沿用 Design-Brief 与现有 OverseasSkillCatalog 的 ElCard/ArtTable/ElDialog/ElMessageBox、蓝色主操作、红色危险操作、换行和窄屏布局。上传独立弹窗，目录树可展开且滚动，进度与错误不挤占表格；下载/删除按钮与平台管理共存，不改现有筛选语义。
