# 单图历史版本交互预览 · 2026-09-22

本轮仅扩展本地 demo/mock；沿用现有前端，不部署、不提交、不调用真实生成 API。这里的版本指图片结果历史，与 Skill 管理无关。

1. 数据：每次成功保存独立结果版本（编号、时间、操作人、修改说明、标注图、基于版本），当前结果指向其中一版。修改失败不新增成功版本，不覆盖历史；恢复旧版后再修改编号继续递增。
2. 界面：结果卡片显示当前 Vn、历史版本入口；弹框左侧版本列表，右侧选中版本与当前结果并排对比，展示修改信息、下载该版、设为当前。恢复需确认，说明不重新生成、不删除其他版本；当前版不可重复恢复。仅初始结果时有一版及提示。修改处理中/失败待重试及打包期间禁切换当前版。
3. 修改弹框显示本次基于 Vn，成功新增并设为当前；ZIP下载使用每张图选定的当前版本。预览提供至少三版的示例入口，减少用户等待。
4. 验证：恢复后再修改编号、历史不可变、失败不新增、ZIP选择、类型/全套测试/构建/浏览器实际交互、1280与1440视觉检查、独立审查。

计划先完成状态与版本弹框，再接卡片/修改入口，随后验证并交付可点击链接。历史版本本轮不提供删除，以免破坏溯源；整任务仍沿用现有删除入口。
