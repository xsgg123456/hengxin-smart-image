# 海外批量标注与逐图参考材料 · 正式实施

用户已确认 `frontend/preview-batch-annotation` 的现有预览，授权正式开发、Git提交和生产部署。本合同为本轮需求及验收依据；保留现有任务、会话、权限、素材、发送幂等、归档和下载机制。

## 交互与范围

1. 每组生成图片增加“批量标注”。同一大画布展示该组真实图片（不限固定六张），支持缩放、平移、选图、框选、画笔、撤销；双击或“放大精细标注”进入同工作区的单图画布，上一张/下一张/返回整组共用状态。1380px单张、1640px批量弹窗沿用已确认样式与正式组件。
2. 意见、标注、参考图以用户/任务/会话/图片ID隔离。批量仅带回有标注的图片，每处标注必填意见；只有参考图而没有标注的图明确提示排除，草稿保留。原组其他图片不重新生成或替换。单张仍可不标注，回输入区补充整体修改意见。
3. 单张与批量右侧均支持本地上传JPG/PNG/WebP参考图，单张20MiB，支持放大、替换、删除、坏图提示/重试。每张选择本产品实拍、成品效果参考或自定义用途；自定义自由多行输入（2000字），非空；每种用途均填写“要参考什么”（2000字）。切换预设不清除自定义草稿，但实际发送使用当前用途。参考图始终绑定当前待改图片，不能跨图错用。
4. 确认前展示实际材料核对；确认后真实上传原尺寸标注图与参考文件，形成输入区修改卡片，不自动发送。失败保留编辑内容并允许重试，不把半批内容静默当成功。支持继续编辑、取消、同图更新去重、再次批量确认移除该组已清空项。关闭保留当前页面未确认草稿；已带回的修改材料沿用既有本地草稿持久化。会话切换、页面刷新恢复已确认材料，未知发送结果使用原请求核实。
5. 真实发送携带待改原图、定位标注图、逐图参考文件及用途/说明。Codex明确原图为编辑底图，标注仅定位；实拍参照商品结构、效果图按说明参照表现，自定义按完整用户用途；参考图不是额外待生成图片。不得将标注画入成品。单图标注意见合计沿用4000字，顶层100附件/100引用生成图限制保持。
6. 历史消息可查看该轮逐图材料、完整用途和意见，绑定发送时冻结的文件及内容；后续编辑、改名、移除素材列表不污染历史。旧消息与旧草稿兼容，既有未知请求幂等摘要保持。

## 实施顺序与完成标准

1. 同步Spec、设计依据、计划；确认数据契约与发布条件。完成标准：文件职责、旧协议兼容和发布方式明确。
2. 后端扩展每个imageEdit的 `references:[{attachmentId,kind,customPurpose,note}]`，kind为product/effect/custom，默认空；文件仍在attachmentIds，冻结inputIndex并验证类型、大小、任务/会话可访问性，安全输出历史DTO。无需新表或迁移。
3. 前端移植已批准画布，使用真实StudioPicture/API；绑定隔离草稿、原子带回、失败重试、历史详情。无预览模拟发送/假数据，不新增生图API或三维旋转能力。
4. 类型/构建/单元回归、实际组件浏览器功能与1920/1440/390视觉、隔离后端与PG集成验证、独立两阶段审查。覆盖2/4张筛选、参考图多种用途、校验、清空/撤销/取消、跨会话、刷新、错误重试、历史冻结、重复文件与权限/篡改拒绝。
5. 审查通过后中文Git提交；按现有海外发布拓扑打包、排空/备份/恢复验证、切换、正式入口视觉与只读验证。保留回滚资料，不为验收触发收费生成。

## 技术依据

沿用仓库Vue3/Element Plus和既有标注SVG、上传服务，不新增运行依赖。嵌套核对弹窗沿用[Element Plus Dialog](https://element-plus.org/en-US/component/dialog)的append-to-body行为。状态按[Vue响应式组件](https://vuejs.org/guide/components/provide-inject)原则保持同一来源；具体绑定以现有组合式状态先例为准。
