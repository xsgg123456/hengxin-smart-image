# API 换套图优化 · 本地交互预览

2026-09-22 用户确认先交付基于现有前端一比一的可操作预览，正式业务实现后续承接。

## 范围与验收

1. 沿用 Art 侧栏、页头、页签、蓝色主题、ArtTable、ElCard、ElDrawer、ElDialog、PicturePreview。记录页52px等比缩略图、紧凑行高、操作人，不重设计整页。
2. demo/mock 专属入口准备全部成功、11张分两批处理中、三次重试耗尽等可重复场景。每批最多10张，当前批全部终态后开始下一批；失败单图等待1/2/4秒重试，首调之外最多3次。进度静默更新，保留滚动、弹框和输入；演示标识明确。
3. 详情保持三列图片网格，显示批次、单项重试、操作人与处理记录。全部成功后提供真实示例ZIP下载，01/02按原图顺序命名，展示打包中、失败和重试。有未完成修改时暂不可打包，避免下载过期结果。
4. 成功图新增修改入口：弹框显示当前生成结果，支持1张标注图及文字（至少一种），提供预览、移除、格式大小校验。使用当前结果+可选标注图+用户说明，不内置业务提示词。模拟修改只影响单图，期间保留旧结果；失败仍保留旧结果，可继续重试；成功更新展示。记录修改和重试操作人。
5. 验证空态、加载、错误、1440/1280布局与裁切、筛选、重复提交、关闭重开、ZIP内容顺序及最新结果。前端类型检查、单测、demo/production构建、浏览器交互和独立两阶段审查通过后交付。

## 计划

1. 主Agent同步需求、计划及设计边界；读取现有页面和样式。
