# 国内 API 换套图重试与上游保护（2026-10-20）

后续范围覆盖：同日用户授权 [提示简化与取消人工核实](API-RETRY-SIMPLIFICATION-20261020.md)。下文为原已发布合同，其中未知结果永久保留、管理员确认恢复、技术提示展示要求由新合同覆盖；其余预算、限速、调度及结果保护保持。

用户已授权开发、测试、Git 提交与生产部署。目标：减少用户反复手动点击，同时优先避免重试放大上游压力。仅国内 API 生图通道；模型、冻结输入、成功图片、海外及 CLI 执行协议保持。

## 已定需求与执行合同

1. 新轮次每图最多 20 次生图尝试（含首次），成功即停；手动重试仅针对失败图片并新开一轮，不设图片生命周期 20 次封顶。不允许在途、未知结果、已请求停止但尚未结束的轮次重开、修改或删除。重复点击同一幂等键返回原轮次，不同键竞争也只能开一轮。
2. 等待采用有上限的指数退避和 equal jitter：第 1/2/3 次重试分别随机 5–10/10–20/20–40 秒，第 4 次以后 30–60 秒。一次抽样持久化，不因刷新、调度或重启重新抽样。遵守 Retry-After 下限，包括 HTTP 日期，不允许抖动把等待缩短到上游要求之前。
3. 从该轮首次发送许可起算 45 分钟；截止或用完次数不再发新请求，已发请求继续收结果。计数在实际网络发送前最后一道放行事务内保守占用：发送与事务无法跨系统原子化，崩溃后不退还不确定尝试额度、不盲目重发。收图重试不消耗生图次数。
4. 请求超时 300 秒，下载 60 秒，租约 600 秒，心跳仍定期续约；发布检查 worker/代理/停机宽限与队列可见性。停止仅阻止后续生成，不能清除在途凭据或丢弃晚到结果。无在途且等待中的停止可结束为 failed 并记录 user_stopped；有在途保持处理中并 stopRequested，终结后可正常重开。
5. 同一 API 通道统一控制首次生成、自动/手动重试及 API 修改：默认全局发送间隔 5 秒、同时在途上限 10（含结果未知的占用），可配置，不能因启动更多进程翻倍；不累积突发额度。素材准备完成、序列化后且网络 POST 前领取共享发送许可，不持数据库锁等待网络。许可之后进程失联按未知处理。不同任务公平准入，不能让老任务无限优先。
6. 通道在连续 5 次可重试临时失败后冷却至少 60 秒；Retry-After 可延长。冷却到期只能一个探测请求，探测期间其他请求等待；成功后先维持低并发，再随成功逐步恢复至配置上限；失败继续冷却。探测令牌/代次持久化，旧请求晚到不能清除新冷却。停止、重试、管理员恢复不能绕过未到期的 Retry-After/自动冷却。冷却只拦新生成，不挡已返回结果下载/保存。
7. 明确临时 HTTP 错误按适配器分类自动重试；账号/余额/参数等不可重试错误停止。请求超时、断线、无法解析的成功响应及进程丢失不能当普通失败重发。当前适配器无已验证的上游查询/幂等能力：进入 uncertain，保留请求证据与容量占用，管理员明确确认原调用已停止后才允许重试。不宣称可自动找回未返回的结果。保留上游 request ID（若返回），不泄露凭据/响应原文到 UI。
8. 等待重试且没有在途/未知占用的任务让出任务并发名额；同图及每任务批次顺序保持。全站任务上限仍 5，每任务最多 10，叠加更保守的通道在途上限。收图与生成限速分离，成功图片/历史版本不重做；不能因公平调度丢失冻结修改输入。
9. 本轮状态、次数、策略版本、首发时间、截止、nextAttemptAt、停止原因、共享限速/冷却/探测持久化。时间以共享数据库/受控一致时钟判定，不能在进程内独立计数。已有成功/失败记录不自动重开；旧在途轮次排空发布，遗留未完成轮次不清零重放，保守维持旧轮规则，显式新轮才使用新策略。
10. 页面沿用现有卡片与按钮，展示真实“本轮 X/20 次”、倒计时、上游冷却/等待名额/需核实/停止原因；提供单图“停止重试”，重复操作和失败提示有明确状态。界面倒计时不得负责调度。自动暂停期间仍可接受合法手动重试排队但不能越过发送门禁；认证等人工暂停仍按现有规则拒绝。

### 历史尝试兼容

生产只读发现旧机制留下97条 `ApiAttempt.state=uncertain`，所关联图片均已进入 succeeded/failed，且没有活动租约；这与新机制“uncertain即仍持有本轮发送所有权”的含义不同。全局预算和发布排空必须按当前图片/轮次/所有权识别活跃调用，不能数全表历史uncertain；不得修改或删除这些审计记录，也不据此宣称上游当时绝未执行。遗留图片本身仍uncertain或有真实活动凭据时继续保守占位。新增独立用例验证历史终态记录不阻断新任务、当前未知调用不能绕过预算。旧无轮次终态详情不伪造本轮0/20。

## 前后端接口合同

- `ApiItem` 增加兼容可选 `retry` 对象：`cycleId: string|null`、`attempts: number`、`maxAttempts: number`、`startedAt: string|null`、`deadlineAt: string|null`、`nextAttemptAt: string|null`、`stopRequested: boolean`、`canStop: boolean`、`reason: string|null`。reason 为安全可读中文，既有 `state`/`error`/`nextAttemptAt` 保持。
- `ApiChannel` 状态增加兼容可选 `cooldownUntil: string|null`、`recovering: boolean`，原 paused 表示人工/认证暂停，不代表临时冷却。
- 新增 `POST /api-image-edits/tasks/{task_id}/items/{item_id}/stop`，请求头 `Idempotency-Key`；响应 `{taskId: string}`，鉴权/共享资源权限、幂等/删除与版本争用遵循既有 API。前端刷新实际任务结果；停止结束标为可重试 failed，处理中仅标记停止后续请求。
