# 海外图片加载与执行时限实施合同

2026-10-30 用户批准开发、测试、中文 Git 提交、打包及生产部署。本合同覆盖先前仅排查及暂停时限调整的限制，不处理此前待审框架建议。

## 产品行为与边界

- 原图预览、缩放、下载、标注仍使用原文件，尺寸、格式、字节不变；小图列表使用独立缩略表示，不将适屏压缩图冒充原图。保持既有布局、标题、切图、键盘和下载交互。
- 当前会话整批图片在后台渐进预取，最多两个原图请求并发。用户点击优先于未开始的后台请求；同图片预取与预览共用在途请求，失败可重试，切换会话取消无用队列。
- 页面内原图 Blob 按当前账号、海外业务、资源 URL 与服务器版本复用；已缓存图片再次打开先校验权限及版本，未改变不再传输原件。关闭预览保留有限缓存；刷新/返回优先利用浏览器私有 HTTP 缓存，允许小型校验请求，不能承诺首次点开未下载完的原图立即显示。
- HTTP 缓存使用 private/no-cache、ETag、Vary Cookie/Authorization；鉴权、记录存在与对象存在检查必须在返回304前完成。禁止 public 缓存及跳过权限的长期 fresh 缓存。401/403/404清除对应页面缓存；账号退出/切换清空并取消在途请求，过期响应不得回填。
- 页内缓存按字节和数量限制并淘汰最久未用项，建议128MiB/40张；只为当前查看及邻图解码，不整批常驻大尺寸解码图。浏览器清理或容量不足时可重新下载，不能无限占内存。超大图片可按需查看但不整批预取。
- 小缩略图接口在现有图片内容URL增加 thumbnail=true；原图URL与内容保持。生成只对受支持图片进行，有像素/字节/并发限制；衍生缓存有容量上限，无需Redis和数据库迁移。读取失败不能改动或覆盖原件。
- 覆盖海外工作台成品、图片附件/任务素材的共同预览组件，归档原图链路保持权限与原件语义，可复用同一缓存策略。非图片大文件继续流式下载。
- 海外配置默认 codex_timeout_seconds=7200、queue_visibility_seconds=7800，国内默认不变。新提交冻结新值，已提交/执行中的轮次保留提交时值，不重放任务。

## 开发顺序与验收

1. 后端：有权限的条件原图响应、独立缩略图与资源限制、海外默认时限及专项测试。验收原件哈希不变，304无body、撤权/删除不得304，缩略图尺寸限制、并发及出错、国内默认不变、旧任务冻结语义。
2. 前端：共享有界缓存、去重/优先级/取消、当前会话批量预加载，接入现有预览而不改布局。验收预取后打开无二次原件GET，重复打开只校验、换图/换账号/删除/失败/容量淘汰正确，预览原尺寸及下载不变。
3. 集成：完整前端类型/单测/构建、后端回归与适用真实环境专项、隔离浏览器验证；固定快照由独立code-reviewer两阶段审查并登记。
4. 发布：版本0.2.55，中文提交后打包审计；从当前实际生产API基线增量安装，保留所有既有账号/授权/Skill配置。先验证实际安装包；停止海外接纳并证明在途排空后，通过独立EnvironmentFile更新worker及outbox的7200/7800配置，保留原生代码目录和启动命令；按实际Compose链增量更新海外API及静态前端。国内与身份服务不重启，无数据迁移。部署后核验健康、配置、图片权限/条件响应、正式页面预览和下载；保留可回退制品及凭据，不恢复业务数据库。

## 分工

- 主Agent：源文档、集成验证、版本、发布工具、独立审查、提交与生产部署。
- 后端执行Agent：backend/app/overseas 内图片交付及配置、相关backend测试；不改前端或发布工具。
- 前端执行Agent：frontend/src 内海外图片缓存与预览集成、相关frontend测试；不改版本号、后端或发布工具。
- 执行Agent不提交、不派生子Agent，彼此不得回退其他人的改动。
