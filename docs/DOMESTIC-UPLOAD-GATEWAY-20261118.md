# 国内工作台附件上传修复

2026-11-18 13:51 至 13:52，国内网关连续三次拒绝数据线工作台的上传请求，记录的请求体均为 10,714,198 字节。国内工作台对应后端接口支持单文件 500,000,000 字节，但内层网关的通用 API 规则限制为 10 MiB，返回 413；页面将 413 显示为「单个附件不能超过 500 MB」。

## 修复范围

用户已授权对共享网关执行本次平滑重载。仅对任务会话的 `/api/v1/domestic-studio/tasks/{task_id}/studio/files` 和兼容入口 `/api/v1/domestic-studio/workspaces/{workspace}/files` 设置请求体上限 500,065,536 字节、流式转发及上传超时，保留国内 API 上游和转发头。65,536 字节用于 multipart 表单开销，后端仍独立核验文件大小、身份和会话归属。

专项入口是当前内网工具目录下的 `release.py upload-apply`。用全局发布锁核对台账、基线配置与绑定文件，先做 Nginx 配置检查，再写入已挂载的文件并平滑重载。两条上传路径及普通 API 对照探测通过后登记网关配置摘要。失败恢复先前配置；发布中断用 `upload-recover`，已生效的版本需要回退时使用 `upload-rollback`。本次无需应用包、数据库迁移或业务服务重启。

## 隔离验证

- 真实 Nginx：两条路径的 10.22 MiB 请求由 413 恢复为成功完整转发。流式发送 500,000,000 字节文件及 65,536 字节封装时上游收齐；超过总上限 1 字节仍返回 413。相邻接口沿用原限制。
- 候选 Nginx → 真实国内 API、PostgreSQL、MinIO：通过有权限会话分别从两个入口上传 10,695,475 字节 PPTX。上传、HEAD 和下载均返回 200；原件、下载文件以及存储对象的大小、摘要一致。另一成员读取返回 404。
