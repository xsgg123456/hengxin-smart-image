# API 换套图交互预览 · 2026-09-22

## 范围与依据
用户要求基于当前前端一比一查看新模块交互。本次只交付现有 Vue / Art / Element Plus 框架里的本地 Demo、截图及可点击预览，不实现或部署生产 API 换图后端。

已确认规则：独立于 Codex CLI；前 N 张为原图、末张为共用素材；每张原图搭配素材请求一次；串行；失败指数退避重试三次。生产实现的错误分类、超时幂等与权限仍在后续计划细化。

## 有序步骤与验收
1. 继承现有布局、蓝色操作主题、hx-page / hx-create-grid / art-card、PicturePreview 与抽屉；新增菜单只在 demo 模式可见，正式路由不开放。以现有替换壁纸页作视觉基准。
2. 新建页提供名称、提示词、有序图片、本地上传、原图/素材标签、前后调整、拖动排序、指定末张素材及移除；支持一键填入五张原图和一张示例素材。图片只在浏览器读取；至少两张有效图片、名称与提示词才可提交。
3. 独立内存 Demo 任务与历史列表，模拟串行进度、失败退避、部分成功、只重试失败项；单图预览/下载示例文件、删除二次确认。关闭详情和切换路由不停止演示，刷新页面重置此新模块，页面明确说明。不写既有 CLI Demo 数据。
4. 提供演示场景选择（顺利完成 / 重试后成功 / 重试耗尽），结果明确为示例，不宣称是用户上传素材的真实处理结果。记录筛选、空态、加载/运行态、部分失败与成功可见。本次只提供单张下载，不伪造整套 ZIP。
5. 类型检查、现有单测、Demo/production 构建；浏览器验证核心交互和无业务 API 请求；截图含新建、进度/重试、结果及 1280/1440 尺寸检查；独立两阶段代码审查。

## 交付边界
本次预览不等于生产功能完成。不保存密钥、不请求中转站、不迁移数据库、不提交或发布。后续根据用户对预览的反馈细化正式开发计划。
