# 新建任务会话隔离修复

## 问题

任务中心点击“新建任务”进入同一处理类型后，可能复用该用户上一次创建会话中的已受理回执。再次提交时，创建逻辑会优先打开旧任务，导致无法创建新任务。

## 修复要求

- 任务中心每次点击“新建任务”都生成新的创建会话标识。
- 模板库点击“使用模板”也生成新的创建会话标识，避免复用旧回执。
- 同一创建会话在登录恢复、详情读取失败或组件卸载重建时继续保留原有草稿和幂等回执能力。
- 新会话必须清空旧的已受理回执、待确认状态和草稿。

## 验收标准

1. 同一用户先提交任务 A，再从任务中心点击“新建任务”，进入创建页后不显示任务 A 的已受理提示。
2. 提交任务 B 时产生新的任务 ID，不跳回任务 A。
3. 原有同会话恢复、待确认提交和显式“另建任务”行为保持通过。
