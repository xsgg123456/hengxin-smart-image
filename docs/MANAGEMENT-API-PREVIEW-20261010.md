## 规划与验收

1. 复用正式侧栏、页头、标签、Element Plus、hx-page、art-card 和管理页样式，保持现有视觉。
2. 调用统计分业务成果和执行消耗；任务、图片、请求尝试、CLI轮次、版本、采用分别计数。支持日期、人员、执行类型筛选和分页，顶部汇总不受分页影响；人员每日明细可展开，关联任务打开 API 任务预览。预览数据明确为模拟示例。
3. 执行监控分 API 生图与 CLI 图片修改，显示队列、运行、等待重试、收图、异常和心跳。支持正常、异常、未知、空闲场景，未知不以零或正常替代。任务打开本地详情预览。
4. 系统配置分别显示 API 和 CLI 的实际作用范围（数值为只读样例）；1天缓存/插件、7天会话/过程清理，正式图片素材和统计摘要保留。统计摘要保留属拟议整改，不声称后端已完成。不提供生产保存按钮。
5. 管理权限、用户角色和 Skill 管理沿用现状。最新菜单已将普通角色限制在API工作区，因此本轮在管理员预览工具中模拟个人统计，不解锁正式权限。日期为北京时间；任务创建、执行开始、产出/采用各归对应事件日期。当前库存与历史发生量分开；请求成功率和图片交付成功率分开；待核实单列。Token/费用无回执显示未提供。
6. 当前预览全部数据为模拟，不将52套/376张包装为实时生产。筛选、明细、分页、加载/空/错误态可交互；本地类型检查、单测、浏览器功能和窄屏视觉检查、独立审查后交付地址。

正式实施后再接真实 API 记录，补操作者归属、独立统计摘要、真实服务心跳和历史回填。不得以预览通过代替生产能力验收。
