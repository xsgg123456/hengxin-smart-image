### 单张标注画布

- 工作区高度固定，意见区独立滚动，首笔及增减标注不再驱动画布重新适配。
- 显示实际图片缩放比例，支持适应窗口、原图100%、鼠标锚点滚轮缩放、空格/中键临时平移。
- 框选八方向调整，拖编号移动标注，框内可新增重叠框；画笔保留合并采样与收笔末点；取消手势回滚。
- 输入框和按钮空格不被快捷键劫持，小图100%居中，无溢出时禁用平移。
- 审查补齐空格准备平移时的抓手光标、拖动中的握手光标及松开恢复，覆盖编号和调整手柄；浏览器矩阵加入光标状态断言。

## 历史材料上线步骤与边界

生产API容器目前无原生worker执行目录访问权。实现将新轮次材料写入数据库供API读取，不扩大运行目录0700权限、不要求挂载私有会话目录。

发布新API、worker及前端后，已有历史任务由原生worker的 `codex` 身份，在其既有应用环境及数据库配置下先运行只读检查：

```text
python -m app.execution.material_backfill --task-id acd13972-1b16-4783-8e89-0d9aff9ecbf3 --round-id cd103910-f824-4ac6-91f7-64b9fbe6b767
```

确认输出后，在同一命令末尾添加 `--write` 冻结历史材料。此命令不调用模型、不重放任务、不修改生成状态；失败计数非零时退出码非零。再次回填不会用无法读取的目录证据覆盖已核实的输入。
