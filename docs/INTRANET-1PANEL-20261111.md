# 内网 1Panel 独立安装

用户授权：在 192.168.1.245 安装 1Panel 面板及基础监控，独立目录，不影响既有系统，交付登录地址及账号。不安装应用商店应用、不接管业务网站/数据库、不改业务源码，不新增收费监控或通知服务。

## 执行计划与验收

1. 只读固定基线：所有现有容器 ID/启动时间、关键 systemd 服务 PID/启动时间、Docker 配置和在用证书摘要、现有健康接口及磁盘使用量。
2. 获取官方稳定版包并核对官方 SHA256，检查实际安装脚本。使用 `/opt/hengxin-monitor/1panel`；严禁默认 `/opt/1panel`（其中现有证书正在被业务挂载）。不安装/升级/重启 Docker，不自动改镜像源或启停既有防火墙；面板端口 10086 需再次查空闲。
3. 安装前独立审查执行适配。只启用面板自身服务及内网访问控制，允许 loopback、192.168.1.0/24、192.168.2.0/23；控制不能影响其他端口。强随机初始密码与安全入口不入 Git，安装原始输出保持私有。
4. 实际浏览器登录，检查首页真实 CPU/内存/磁盘/网络及监控采样。监控启用，保留 15 天。核对无新增业务应用，记录实际默认采集间隔。
5. 用相同口径复查基线：既有容器/原生业务服务未重启，配置与证书摘要不变，原有入口和两侧 readiness 正常；记录安装目录、系统二进制、准备包等新增占用以及整盘变化。整盘变化包括同时发生的业务写入，不冒充面板独占占用。

## 回退边界

如面板安装失败，仅停止并禁用新增 1panel-core/agent 服务；确认服务已停止且10086不再监听后，禁用并撤销本次面板专属访问规则。如停止失败则保留访问限制，避免暴露未完成初始化的面板。保留私有诊断资料。不运行可能清理共享目录或影响 Docker 的通用卸载脚本。原业务配置、数据、证书和服务不作为回退对象。
