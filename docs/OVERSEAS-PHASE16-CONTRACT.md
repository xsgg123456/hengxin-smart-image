# Phase 16 运行与就绪合同

本阶段仅交付海外独立运行基础，不交付身份、业务权限或实际 CLI 调度。

- 直接复用 Settings 的公共校验、数据库进程连接池、MinioStore、错误处理和 HTTP 计时；海外只新增配置入口、迁移元数据及依赖检查。
- 进程必须显式使用 `HX_BUSINESS_CONTEXT=overseas`，资源仅取 `OVERSEAS_` 环境变量，不加载国内 `.env`。国内入口拒绝海外上下文。
- 海外迁移版本表为 `overseas_alembic_version`，本阶段目标版本 `overseas_0001`；国内与海外迁移入口互斥，海外元数据不得注册国内表。
- `GET /api/overseas/v1/health/live` 只表示进程存活。`ready` 必须检查数据库版本准确匹配、Redis 认证连接及目标 MinIO 桶存在且无匿名策略；任一失败返回503，仅公开依赖名称和 up/down，不公开错误、地址或凭据。
- 就绪检查不创建桶、不写业务数据、不运行迁移。存储客户端复用一期实现，并允许健康探测指定较短 HTTP 超时。
- 初始化/迁移使用独立管理凭据；API 只获得海外运行凭据，没有数据库DDL、MinIO管理权限或国内凭据。独立Compose不挂载国内卷，不启动一期Worker；实际海外Worker在Phase21实现。
- 验证使用可销毁的本地测试实例，覆盖真实迁移、依赖故障、跨业务凭据双向拒绝及一期回归。生产资源不在本次范围内。
