# Skill 平台分组与工作台两项优化 · 正式实施合同（2026-11-02）

用户已批准以 preview-skill-platforms 的交互为准正式开发、中文 Git 提交并部署生产。

## 范围与验收
1. 管理页沿用真实布局；六个目标平台 Amazon、Wayfair、Mercado Libre、Walmart、The Home Depot、Shopee，另有全部、未分组。暂不扩展平台字典 CRUD 或品牌维度。
2. 一个已安装 Skill 可关联多个平台；支持名称/描述搜索、状态筛选、单项编辑、批量覆盖平台、添加已有 Skill 到当前平台（并集）、移出当前平台（只删该关联）。编辑弹窗及批量提交真实持久化，有版本冲突与审计，失败保留草稿并提示，不假成功。全局启用开关沿用原指定账号权限；平台配置使用现有 skills.manage 管理权限，普通设计无管理写权限。
3. 工作台只提供已开启且关联当前任务目标平台的 Skill；无匹配仍可不选 Skill 发送。后端新提交也校验平台匹配。旧草稿失效选择提示并保留其他草稿；已提交轮次幂等返回优先、冻结包、历史会话及已运行任务不改。
4. 平台关联独立存库，不修改已安装包中的文件、名称、描述、字体、提示词、执行流程。初始按现有十五项已确认预览配置归类（Amazon10、Wayfair2、Walmart2、未分组1），不重置现有开关；新安装未知 Skill 默认未分组。历史平台值不改写，没有匹配则提供无 Skill 对话。
5. 工作台 Skill 下拉仅名称，仍可搜索名称；选中后主动查看说明保留。管理页名称和完整描述保留。
6. 取回文件弹窗在列表上方增加可清空搜索，文件名或路径包含匹配、忽略英文大小写；即时筛选、结果数、无匹配提示；勾选跨搜索保留、计数覆盖隐藏项并提示隐藏已选数量。保持原权限、100项/500MB、刷新、真实取回、错误重试和会话隔离。

## 实施顺序与完成标准
1. 后端关联模型/海外迁移、版本校验批量事务、权限审计、工作台列表与新提交校验；以迁移保留开关、跨平台拒绝、幂等兼容及原功能回归为完成标准。
2. 前端以已审预览接真实API，去除演示控件；下拉与取回搜索复用原组件；正常/空态/失败/冲突与勾选保留测试通过。
3. 全套适用回归、类型/构建、实际安装包与数据库迁移验证、浏览器实测，独立两阶段固定快照审查。
4. 只增量发布必要海外API和前端；实查生产基线、备份且隔离恢复、排空必要服务、保留国内与原生执行服务、全部Skill字节哈希前后相同。中文Git提交、受审制品上线，正式页面与权限/平台筛选/取回入口复验；保留恢复材料。
