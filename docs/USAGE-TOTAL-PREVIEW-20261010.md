# 累计图片产出与每页条数交互预览

用户确认口径：首次生成10张、修改成功生成3张，累计生成13张。调用统计默认全部时间、权限范围内全部人员；移除原图库存；换图记录增加20/50/100条选择。用户本轮仅授权预览，拍板后才改正式业务代码。

## 预览规划与验收

1. 在 output/usage-total-preview/frontend 建立前端独立副本，复用现有框架、样式与组件，不修改正式前端、后端或生产。
2. 累计生成图片为首要指标；首次生成与修改生成分项求和，API修改与CLI修改均纳入修改。失败、上传素材不计；采用与恢复不重复计数。示例使用确定性模拟数据，不冒充生产历史核算结果。
3. 默认全部时间、全部人员、全部生成类型；筛选与重置、日报分页与明细可交互，汇总覆盖全部筛选结果。原图库存相关块和指标全部移除。
4. 换图记录延续实际页面布局，每页20条默认，可选50/100条；切换回第一页并保留筛选。只操作模拟数据，不发起任何生产请求。
5. 浏览器验证两页、分页、筛选、汇总不随翻页变化、空态及窄屏；类型检查与独立审查后提供本地预览地址。此预览不证明历史数据已被重新核算，真实数据整改待用户拍板。
