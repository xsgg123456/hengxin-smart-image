# API 单图 CLI 多轮修改实施记录

## 已对齐范围

图片修改调用 Codex CLI；API 首次换图、文字修改和旧 CLI 套图功能保持。原图片修改固定提示词及逐条/整体意见拼接保持，执行层附本轮文件角色、底图和交付约定。新结果为候选，采用才更新 API 当前成品。

前端直接复用真实 AnnotationEditor 和 AnnotationCanvas，不能用静态预览重写其功能。工具位置、框选、画笔、编号意见、缩放、平移、撤销、删除、上传标注、预览确认保留；多轮历史和生图过程按需展示。

## 实施顺序及验收

1. 数据与执行：每 item 独立会话，每轮完整输入快照，幂等和活动轮次互斥，精确续接，候选显式采用；测首轮/续接/文字回复/候选/取消/迟到结果/尺寸。
2. SSE：持久事件编号，鉴权后按游标补发、去重和心跳；连接关闭不取消任务，禁用或删除后终止访问；只发布用户可见播报。
3. 前端：继承原布局，关闭恢复、标注按轮次保存、历史底图选择、采用冲突提示；文本修改模式不串入。
4. 集成：类型检查、单测、构建、隔离浏览器流程、迁移检查、代码快照独立两阶段审查。此次不自动部署，也不发真实收费生成请求。

## SSE 运维约束

事件响应使用 `text/event-stream`，以 `id` 表示持久游标；重连遵循 `Last-Event-ID` 并支持首次订阅显式游标。不能只保存最近一屏事件作为唯一历史。参考 [WHATWG SSE 标准](https://html.spec.whatwg.org/dev/server-sent-events.html)。

`infra/nginx.vps.conf` 和 `infra/nginx.media.conf` 对 conversation/events 路径关闭缓存、压缩与代理缓冲；外层 `nginx.zhitu.qhhengxin.top.conf` 已关闭响应缓冲。75 秒代理读超时由周期心跳维持，不用提高全站超时。生产部署时必须核对实际使用的完整配置链，不能只更新前端文件。

长连接每次读取事件需短事务并释放数据库连接，避免占满连接池。执行流程不依赖浏览器在线；连接重建不重新执行模型。已有 CLI 若只发完整公开消息，则 SSE 整条发送，不能声称已实现上游逐 token 输出。

## 使用与兼容

换图记录中点击“修改图片”，图片模式继续使用原来的三图参考、框选/画笔和修改意见。确认提交后可关闭窗口；重新打开恢复同一图片的会话。每轮结果先作为候选，可在该图上继续标注提交，点击“采用此图”才写入新的正式版本。文字答复作为“等待回复”呈现，不伪装为图片生成成功。

“修改过程与历史”按需展开，用于查看公开播报、每轮底图/标注/候选及修改提示词。已发布版本与历史候选可以作为下一轮底图；标注仍与其对应底图绑定。文字修改继续走原有 API，不共用图片会话。

旧 `/revise` 图片修改 API 保留兼容历史客户端，但与 CLI 会话互斥；本次新版前端图片入口统一调用 `/conversation`。新会话需要迁移 `0023`、API/worker 同步更新、既有 CLI 执行开关和隔离运行环境启用，以及上述 SSE 代理配置。不能只上线前端。

租约丢失或进程状态无法确认时，轮次标记“待核实”并禁止自动重跑；停止请求交由执行节点核验进程身份并确认退出后释放。不能确认的情况保留状态供管理员处理，避免另起进程重复执行。
