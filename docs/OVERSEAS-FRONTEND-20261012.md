# 二期海外生图：前端实施与验收

## 已确认需求

用户指定 `output/海外生图系统-独立原型-六节点版.html` 及 `output/overseas-prototype-20261012-v2/原型说明.md` 为二期 PRD 基准；本文件固化原型语义与新增权限需求，原型中的示例不固化为业务规则。

- 运营提交图需 → AI 排版分析 → 设计确认方案 → AI 生成图片 → 设计逐图审核 → 成品归档。
- 品名、品牌、多 SKU 贯穿全流程，SKU 不包含颜色字段；图片需求文件和竞品分析表格至少一份。提交前提示核对，不设资料审核或退回运营。
- 设计填写方案修改意见后重新分析，通过后生成；单张图可画布标注返工，仅影响对应 SKU 的图片；全部图片通过才能整套归档。
- 按品名 → 品牌 → SKU 查找成品，沿用提交信息，不采集或展示 SKU 颜色。原型六张仅为示例，正式张数由确认方案决定。
- 复用一期现有 Vue、Element Plus、Art 风格、品牌、登录视觉和可复用组件；本轮正式编写可继续接后端的 Vue 源码，不嵌入旧 HTML。
- 钉钉身份认证后显示国内业务、海外业务两个入口。无相应权限时入口置灰并显示暂无权限。业务角色独立，同一个人可在两套业务具有不同角色，国内管理员不自动获得海外权限。
- 后续真实接入必须使用独立海外数据库及数据库凭据、独立业务鉴权、数据与文件授权边界；不得以一期数据库加业务字段代替独立数据库。是否独立服务器不在本次承诺范围。

## 本轮范围

2026-10-12 用户再次明确：直接复用一期已存在前端，不重造界面底层。落实为 LoginLeftView、AuthTopBar、ArtSidebarMenu、ArtHeaderBar（新增兼容账号插槽）、ArtPageContent、ArtTable、ElUpload 和 AnnotationCanvas 的直接组件复用；独立 Pinia 不安装持久化插件，复用路由实例但不安装一期业务守卫/启动器。语言初始化在隔离预览构建下不读取一期用户存储。账号插槽默认行为不变，海外预览替换国内退出逻辑。

交付正式前端模块及本地预览入口；预览使用独立内存数据与模拟身份，不调用国内接口、不读取国内会话和业务存储，不接钉钉、AI 或数据库。模拟功能明确提示，刷新重置。正式一期登录和业务行为保持兼容，待真实业务授权接口完成后接通双入口；不得将前端限制宣称为后端权限隔离已完成。

## 有序实施

1. 登录与业务选择：`frontend/src/overseas-preview/` 挂载现有品牌/登录组件和正式海外模块；独立预览 HTML 与 Vite 构建入口。验收授权模拟、双入口、单侧/双侧/无权限、退出与禁止直接访问。
2. 工作流模块：`frontend/src/views/overseas/` 存放类型、独立预览适配、提交、任务列表、方案确认、审核及归档组件。验收多 SKU、至少一份文件、重复 SKU、角色限制、方案返工、单图标注返工、整套归档、删除/移除、空态与失败重试。
3. 视觉与回归：沿用一期 hx-page、art-card、Element Plus 变量及原型布局；宽屏和窄屏内容、按钮、标注完整可达。执行类型检查、前端全单测、正式及预览构建、隔离浏览器流程；独立 code-reviewer 两阶段审查并登记快照。

## 后续交付顺序

前端评审后先建设海外独立数据库、身份到业务角色的独立授权接口与文件存储授权，再接资料解析/CLI 分析生图，最后真实多角色隔离、失败恢复及上线验收。本轮不部署、不提交、不修改一期数据库。


## 2026-10-12 二期预览修订
- 统一复用钉钉身份认证，授权一次后选择国内/海外业务；业务角色、权限、数据库仍独立。不建设第二套钉钉认证。本轮本地预览继续模拟认证，不接生产。
- 登录页与业务选择页移除模拟身份、权限场景、授权结果配置和底部说明；入口只显示国内业务、海外业务，取消简介与重复标题/按钮。无权限仍禁用并提示暂无权限。
- SKU 不含颜色字段：同步移除提交、类型、校验、详情、方案、成品检索和示例中的颜色维度。
- 海外独立管理中心参照一期五项：调用统计、执行监控、用户与角色、Skill 管理、系统配置。复用一期 Art/Element 组件和布局，使用海外独立内存数据。统计和监控从海外任务计算；用户角色和配置提供本地预览操作，不访问国内管理 API。
- 管理中心仅海外管理员可访问；预览顶部角色切换提供管理员体验，国内管理员权限不继承。业务流程运营/设计权限维持原规则。
- 实施顺序：统一登录及简化入口 → 删除颜色 → 海外管理中心 → 单测、类型构建、浏览器流程及独立两阶段审查。

预览默认海外管理员，便于直接查看管理中心；管理员在提交工作区使用运营操作权限，设计审核需切换设计角色。URL 场景仅用于自动验收，不在登录页面暴露；正式授权由统一钉钉身份映射到独立业务角色。
