# 用户可见时间统一北京时间

## 需求与证据

用户指出海外任务提交时间直接显示 `2026-10-14T00:59:59.091561+00:00`，应显示 `2026-10-14 08:59:59`，并要求检查全系统同类问题。Product-Spec 已规定统计按 Asia/Shanghai 自然日归属；本次扩展到国内、海外与成员申请的全部业务时间展示。

代码证据：OverseasWorkspace 的 createdAt 列没有展示插槽，OverseasTaskInfo 等直接插值时间；国内多个组件使用未指定 timeZone 的 toLocaleString，随浏览器所在时区变化。后端 app/models.py 的 utcnow 使用 timezone.utc，持久字段为 DateTime(timezone=True)，正式时间带 UTC/偏移；旧前端模拟资料使用无时区的年月日时分字符串。

## 实施与验收

1. 新增共享格式化工具：显式 Asia/Shanghai，固定 YYYY-MM-DD HH:mm:ss；带偏移时间按其实际瞬间转换；无时区旧显示字符串按北京时间解释；缺失/非法时间返回占位，不能泄漏 Invalid Date。
2. 国内、海外及成员申请所有业务时间展示接入共享工具，覆盖列表、详情、事件、材料解析、历史版本、归档、管理记录。仅格式化展示，不改 API 原始时间、排序与耗时。
3. 海外管理 datetime 筛选明确北京时间，输入墙上时间转 +08:00，避免国外浏览器提交错时区。
4. 回归包含用户原始样例、跨日、不同偏移、旧数据、缺失与非法值，以及非中国浏览器/运行环境。运行前端测试与类型检查，独立审查由主线程完成。

## 范围

直接复用原业务页面及展示函数入口，新增一个无第三方依赖的共享时间工具。模板工程未进入业务的示例聊天/日历不属于产品业务页面。无时区数据只用于兼容旧显示数据，不将后端存储时间重写成北京时间。
