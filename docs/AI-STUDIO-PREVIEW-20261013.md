# AI 设计工作台独立交互预览

授权：仅前端交互预览。继承现有海外外框和样式，四个节点合并成一个工作台。正式后端、部署、真实生图不在范围。

1. 复用布局：使用 OverseasShell、Art 导航、现有主题及 Element Plus。完成标准：桌面视觉与现有页面一致，四步状态条为提交、预审、AI设计工作台、归档。
2. 简单开放对话：选择 Skill，上传/移除多张图片与 PDF/PPTX/Word/Excel 等文件，输入意见、模拟发送/停止。完成标准：附件可预览或下载；纯附件可发送；无输入阻止发送；选择的 Skill 和附件跟随该条消息记录；明确模拟。
3. 图片与归档：直接在回复里展示授权参考图片作为示例，放大、引用修改、勾选、归档确认、查看本地归档；完成标准：无选择/执行中不能归档，取消无改变，归档可移除，刷新重置说明明确。
4. 验证：独立入口与构建、桌面和窄屏浏览器实际交互、独立两阶段代码审查。预览不访问业务 API，不更改正式路由。素材来自用户提供 Skill 的已归档样图，明确不是本次生成。

源代码：hengxin-smart-image/frontend/preview-ai-studio/。复用已有前端依赖，不安装新库。预览内状态仅内存，刷新重置。不改正式流程，DEV-PLAN 正式阶段不变；正式采用后另行同步。
