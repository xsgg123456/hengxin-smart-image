## 一、图片加载方案（已批准实施）

### 核查结论

- 2026-10-30 提交 `0aa5912` 引入海外图片缓存优化，`8f2bde2` 补充生产验收；版本为 0.2.55。参见 [原实施合同](OVERSEAS-IMAGE-CACHE-IMPLEMENTATION-20261030.md) 和 [生产交付记录](OVERSEAS-IMAGE-CACHE-RELEASE-20261030.md)。
- 工作台已使用缩略图、共享原图缓存、在途请求去重和限并发预取。归档后端也已支持 `thumbnail=true`、HEAD、ETag 和鉴权后的条件响应。
- 成品库前端未接入这套机制：封面与详情小图使用 `use-archive-image.ts` 下载完整原图 Blob；详情图片挂载后分别发请求；查看器单独加载当前原图，切换或卸载释放旧数据。`api/overseas/archives.ts` 图片请求使用 `cache: 'no-store'`。
- 相关加载组件最后修改于 2026-10-16；与 10月30日提交对比，未发现后续回退缓存优化。属于接入范围尚未覆盖，不能把此前工作台验收视作成品库已优化的证据。

### 确定方案

1. 成品库列表封面、详情图片卡片使用已有独立缩略图接口；保持原比例、既有布局、加载失败及重试提示。
2. 放大查看器接入已有海外共享原图缓存；预览、缩放及下载保持原件字节、格式和分辨率。详情下载按钮独立于缩略图加载，不因未下载原图而长期不可用。
3. 打开成品详情或查看器后，对当前套图片渐进预取原图，最多两个原图请求并发；点击当前图片优先于未开始的后台请求。列表封面不触发所有套图原件的批量下载。
4. 预取与预览共享在途请求；关闭再打开、前后切图复用有限缓存。沿用128 MiB/40张上限及淘汰策略，超大图片按需读取；离开当前套图或切换筛选时取消无用预取，已完成缓存按预算保留。
5. 使用浏览器私有条件缓存及权限、版本校验，避免未变化原图正文反复传输。账号退出或切换清理缓存，撤权、删除、资源失效仍正确拒绝并清理对应缓存。继续使用归档独立资源 URL，不以文件名或外观相同为由跨任务复用数据。
6. 复用已有缓存与缩略图能力，不另建一套并行缓存系统。预计以前端接入为主，不新增数据库字段；实施时根据集成证据确定必要的最小调整。

### 验收标准

- 封面和详情小图实际请求缩略图；打开列表不下载整套原图。
- 原图预取并发不超过两个，点击优先，在途去重生效；切换或关闭后无用预取停止。
- 已缓存图片再次预览只做必要校验，未变化时不重复传输原件正文；刷新后的私有HTTP缓存复用有网络证据。
- 验证首次冷加载、重复打开、切图返回、筛选、失败重试、缓存淘汰、退出换号、撤权及归档删除。
- 查看器原图尺寸和下载文件哈希保持，原任务删除后仍可正常查看独立归档。
- 记录请求数、传输字节和加载耗时，分别报告冷缓存与热缓存；不承诺首次未完成下载的原图秒开，不将工作台旧验收结果代替本次成品库验收。

## 二、归档六字段统一（已批准实施）

归档弹窗仍使用三字段 `StudioArchiveFields.vue`，成品详情已使用六字段 `OverseasArchiveFields.vue`；任务与归档接口已提供任务名称和语言。

建议两处共用基础信息展示规则，按以下排列统一标签、顺序、字号、标签宽度、空值及语言中文名称：

| 左列 | 右列 |
| --- | --- |
| SKU | 目标平台 |
| 品牌 | 任务名称 |
| 品名 | 语言 |

- 来源会话及所选图片数量保留在说明区。
- 基础信息展示整套任务SKU；历史多SKU任务另保留“本次归档所属SKU”选择，避免将整套SKU与本批图片归属混淆。新建任务目前仅单SKU。
- 归档详情继续读取独立快照，不随意覆盖历史快照；历史语言缺失显示“未设置”，不猜测补填。
- 验收同一任务归档前后字段名称及相应值，覆盖历史缺值、多SKU、长名称、窄屏和归档操作。
