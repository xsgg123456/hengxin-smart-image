# API 单张修改双模式预览

范围：用户要求基于当前前端一比一预览。仅本地隔离交互原型，正式需求、生产入口和后端提示词尚未变更。

1. 复用现有 Element Plus 弹窗及 AnnotationEditor/AnnotationCanvas，保留1380px弹窗、左画布右意见、工具与提交预览。完成标准：同组件实际渲染。
2. 增加图片修改/文字修改选择，说明、提示词、确认类型同步变化；两种模式草稿隔离且切换保留。完成标准：浏览器切换可验证，预览提示词正确。
3. 图片修改固定提示词为适用于不同图片、对象和局部编辑要求的通用模板，不能包含当前示例图片的对象或目标位置。具体修改内容仅来自当次用户意见和标注；两种模式初始意见为空，文字模式沿用现有提示词。提供“查看固定提示词”，即使未填意见也可查看模板，完整提交提示词另行组合用户实际输入。完成标准：固定模板可单独查看、完整提示词可展开，空意见被拦截，标注可选。
4. 使用用户截图作预览背景及画布素材展示来源；并非服务器原始800px图片。确认提交仅演示提示，不联网生图。完成标准：检查浏览器无业务API请求，头尾及按钮可见。

入口：前端 preview-single-edit/index.html；独立 Vite 配置，无生产路由接入。待用户确认交互后再同步正式 Spec、设计及开发计划。
