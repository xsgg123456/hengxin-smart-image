## 行为及兼容

- 提交和退回重提共用表单新增“语言”必填下拉单选；默认留空，选项依次英语、德语、法语、西班牙语，接口字段 `language` 为 `en/de/fr/es`。前后端均拒绝缺省、空值和其他值。语言随图需保存，并在图需详情可查看。
- 新建目标平台默认留空、提示“请选择目标平台”，保持必填。编辑已有任务保留已有选择，不清空历史平台。保留现有平台选项、品牌及其他校验。
- 归档成品详情顶部展示 SKU、目标平台、品牌、任务名称、品名、语言六项；标签与提交图需一致。复用既有组件与布局，不要求归档时再次填写。
- Task 新增可空 language 列用于兼容旧记录；新写入接口要求有效语言。Archive 新增可空 task_name、language 快照，创建归档时自动从任务复制，保留既有 SKU/平台/品牌/品名快照及删除后独立可读性。
- 迁移只给仍有关联任务的历史归档补充真实任务名称/语言；没有可确认来源的信息显示“未设置”，不猜测语言、不编造任务名、不覆盖既有业务值。历史任务可继续查看、审核、设计与归档；重新提交时必须选择语言。
- 不修改 Skill 内容、不增加模型调用；沿用既有权限、幂等与版本控制。旧 market/remarks 兼容行为保持。
