# 工作台与归档信息正式实施 · 2026-10-19

用户已授权按对齐后的五项需求正式开发、中文 Git 提交、打包部署生产。预览目录仅为设计参照，不接入生产构建。沿用当前 Vue/Element Plus、FastAPI/SQLAlchemy 和既有部署拓扑，不升级依赖。

## 实施与验收合同

1. 每轮公开执行过程独立成组：执行时默认展开；成功输出最终回复后自动折叠，最终正文与正式图片在折叠组之外。历史成功轮次重新进入默认折叠，用户可手动展开；失败/停止保留可见过程，正文不得丢失或被重复显示。仅处理已有公开 transcript，不增加内部推理采集。
2. 成品库卡片、详情、工作台归档确认明确标注品名、品牌、平台、SKU。平台按 Amazon 等平台字段，不增加国家站点。去掉卡片顶部重复品牌标签，保留已归档状态、原封面/下载/权限行为。
3. 实际保存操作者由服务端认证身份确定，记录归档时间与本次涉及图片，详情可查看历史操作，卡片显示最近归档人/时间。归档审计不能用任务创建人或设计负责人代替。历史数据只有可核实证据才能回填；无法核实显示“历史记录未记录”，不得猜测。保持幂等、事务、授权、任务删除后快照和图片保护。
4. 归档确认保留所属 SKU 选择，展示当前任务真实产品信息与所选数量；归档成功后可继续对话。取消无写入。
5. 鼠标按钮与 Enter 共用正式发送路径；Shift+Enter换行，兼容既有Ctrl+Enter。中文组合输入与229边界不误发，长按不重复发送；空输入/上传中/进行中/待核实/无权限等既有门禁保持，附件、标注、Skill和幂等完整保留。

## 有序执行计划

1. 核对源代码、真实生产版本/迁移/任务状态；同步需求及计划。完成标准：范围清楚、版本拓扑有只读证据。
2. 独立实现工作台过程/发送和归档字段/真实审计。完成标准：正式API及UI具备上述行为、针对性测试覆盖历史与失败边界。
3. 整合、前后端全套回归、类型和生产构建、隔离HTTP及真实浏览器验证、独立两阶段审查。完成标准：批准快照与实际代码一致，已知环境跳过明确记录。
4. 中文Git提交，生成带清单的生产包、隐私检查和实际镜像安装测试；按既有机制停止接纳、排空、备份并验证恢复，迁移及切换。完成标准：健康/版本/真实页面验收通过，原生产数据和国内/身份服务不受影响，保留可用回退资料。不触发收费模型或删除真实业务记录来验收。

## 分工边界

- 工作台实现负责正式 studio 前端（含归档确认）、过程/键盘测试。归档确认字段从task读取。
- 归档实现负责 archives 后端/迁移/API及正式成品库卡片/详情/审计测试，不改 OverseasStudio.vue。
- 主Agent负责文档、版本、集成与浏览器、发布脚本/测试、审查、Git和生产部署；共享编辑先协调，其他人不提交、不覆盖别人的改动。
