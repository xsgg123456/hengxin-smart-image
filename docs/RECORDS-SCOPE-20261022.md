- 每次从菜单重新进入默认“我的任务”，按任务最初创建人（owner_id）匹配当前已认证账号；他人修改不转移归属。切“全部任务”后支持搜索选择创建人，包含仍有历史任务的停用成员，不按重名姓名筛选。
- 沿用已确认预览的Art框架、范围tab、四张统计卡、人员/状态/时间/名称或编号搜索、范围说明、20/50/100分页和52px缩略图。人员只在全部下显示；列表“操作人”改“创建人”。正式页面不带预览标记、场景选择、示例任务或固定日期。
- 时间默认全部，今天/近7天/近30天及自定义日期按北京时间自然日含首尾查询；近7天含今天及前6天。日期范围不完整时不施加时间条件，提示选择完整范围；倒置范围拒绝。任意筛选及每页数量变化回第1页，先筛选再分页，最新创建优先、同时间以id稳定排序。
- 四卡统计全部匹配记录：任务套数、排队/处理中套数（queued/running/uncertain，沿用原口径）、成功图片（succeeded）、未完成图片（failed，沿用原口径）。翻页不变；不以当前页替代全量汇总。接口缺汇总时显示未知而非假零。
- 详情关闭、手动刷新、静默轮询保留筛选及页码；重置清空人员、状态、时间、搜索但保留我的/全部范围。新建返回记录默认我的。空态区分无任务和无匹配，提供清空筛选、新建、查看全部入口。错误保留同查询上次数据并明确提示；改变查询不能把旧范围数据冒充新范围结果。
- 保留现有详情/图片/历史/下载/重试/删除权限及真实动作。仅默认视图变更，不收窄或扩大共享权限；所有后端接口仍验登录和shared_resources。账号切换不复用前账号结果。

## 接口契约

`GET /api/v1/api-image-edits/tasks` 增加 `scope=mine|all`（HTTP默认mine）、可选`creatorId` UUID、可选`dateFrom/dateTo` ISO日期。mine根据服务端认证身份过滤，不信任客户端身份；mine同时提供creatorId拒绝422。all不指定creatorId查询权限内全部。日期至少单边可用，end为翌日北京时间0点的开区间。

保留既有items/total/page/pageSize/view；每个summary增加`creatorId`，响应增加`stats: {tasks, pendingTasks, successImages, failedImages}`。列表、total、stats使用同一筛选条件，汇总用SQL而非下载全量任务。旧内部list_tasks调用默认不附人员条件以兼容内部用途，HTTP边界负责mine语义。

`GET /api/v1/api-image-edits/creators` 返回`{items:[{id,name}]}`，取未删除任务创建人及当前用户，不包含登录标识、角色、手机号等身份详情；使用共享资源权限，不调用仅管理员可用的用户管理接口。
