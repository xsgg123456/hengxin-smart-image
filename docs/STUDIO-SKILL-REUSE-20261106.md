# 同会话技能内容复用 · 2026-11-06

用户授权：开发、Git 中文提交并部署生产。同会话同内容技能复用，切换技能/内容版本准备新份，保留历史会话与全部上下文。

## 规则与边界
- 仅海外 Studio 持久会话启用；国内及旧非 Studio 执行保持原行为。
- 以技能名称、全部相对路径、文件字节校验及执行权限规则确定内容身份，不能只按显示名或发布批次判定。A→A复用、A→B新建、B→A复用、A内容变化保留两版；相同内容重发不增副本。
- 同会话私有技能库放在会话根目录下独立目录；只把当前选择的版本只读挂载到既有技能路径，不能把库暴露给模型，也不跨会话共享可写内容。不选择Skill时仍不得发现旧技能。
- 已安装技能及数据库冻结技能两种来源都覆盖；复用时验证完整文件清单/大小/校验值，上传资源命中后不重复下载。异常明确失败，不能静默用其它版本。
- 首次写入暂存、校验、原子发布；同会话准备互斥；拒绝链接、特殊文件、越界、额外文件及损坏，不覆盖已有版本。沿用现有会话执行互斥与删除保护。
- 不删除、重写或摘要原会话、历史、附件、工作文件、生成图、旧轮次副本。旧会话下一次选Skill时开始使用新库，旧副本不批量迁移/回收。本轮收益为阻止后续重复增长，不声称立即回收既有916MB。
- 不改UI、数据库结构、模型、凭据或技能内容；本次不扩展定期清理和跨会话去重。

## 有序交付与完成标准
1. 更新Spec/计划/变更记录。标准：授权、作用域、保留要求与验收清晰。
2. 实现同会话版本库，接入materials.prepare；标准：两来源、命中/切换/升级/取消选择兼容，文件权限与沙箱挂载通过。
3. 测试并独立审查。标准：A/A/B/A、内容改动、独立会话、并发、失败重试、损坏/链接/越界、旧会话继续、上下文字节不变、删除兼容；后端回归、编译、前端既有类型/测试/构建及Linux真实身份/只读挂载验证。既有失败与新回归区分。
4. 固定审查快照、中文Git提交、打包。标准：独立两阶段PASS、包只含已审源文件及测试，无用户数据/密钥；运行服务对应实际安装路径测试通过。
5. 生产发布并验证。标准：读取最新部署证据、基线与在途状态；停止接纳并排空后切换海外原生服务，保留回滚；UI/API/数据库不需切换。核对会话/上下文保留、服务健康、安装哈希和隔离真实挂载复用验证；不调用收费模型来冒充全会话实测，不重放用户任务。
