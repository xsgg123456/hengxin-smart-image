# 恒鑫智图 · 现有框架交互 Demo

基于 `hengxin-smart-image/frontend` 的 Vue 3、Element Plus、Art Design Pro，复用真实侧栏、头部、工作页签、路由、表格、弹窗、抽屉及业务接口契约。旧纯 HTML 原型已清理；正式前端是唯一维护源。

## 运行

在 frontend 目录执行 `pnpm dev:demo`，访问 http://127.0.0.1:3010/?role=super_admin#/image-processing/wallpaper 。现有依赖已安装，本轮未升级依赖。

构建：`pnpm build:demo`，产物 `dist-demo/`；静态预览：`pnpm serve:demo`。独立3010端口避免与3008的原开发环境共用存储。不要双击 index.html，必须经本机 HTTP 服务打开。

生产构建执行 `pnpm build`，默认 production 模式连接真实 API；只有显式 `demo` 才启用本机持久化假数据，`mock` 保留原内存测试行为。Demo 本身不部署线上；2026-09-22 已授权将共享组件的 UI 改进发布到正式前端，完成状态见本轮发布记录。

## 推荐体验顺序

1. 替换壁纸：点击选中模板缩略图，在大图里左右切换；点击“更换模板”检查图片查看与模板选择是两个操作。
2. 点击“使用示例素材”或上传 JPG/PNG/WebP，填写任务信息，提交后进入原框架任务抽屉。
3. 结果网格优先展示；点图可看当前整套。可单张修改或整套修改，版本增加，历史版本只查看及单张下载。
4. 下载整套得到实际 ZIP；归档使用各位置当前版本，成品详情支持看图、下载及返回来源任务。
5. 模板库新建/编辑/排序/历史/删除；管理中心体验统计、监控、用户角色、Skill及配置。
6. 顶部切换角色/失败场景；慢图有加载态，坏图可重试，部分失败可恢复；“重置当前 Demo 场景”带确认。

## 数据与边界

- Demo 的上传、模板、任务、结果版本、归档、配置及成员修改保存在当前浏览器的 IndexedDB。刷新后保留。不同浏览器/端口不共享。
- 角色共用同一场景的数据；业务场景和管理场景组合分别存储。重置只删除当前组合。
- 同一场景只允许一个标签页操作，第二标签页明确提示，以免覆盖数据。
- 模拟执行在页面打开时推进，刷新继续同一轮次。关闭所有页面期间不会后台运行真实生成。
- 本地示例图用于交互演示；版本增加不代表实际 AI 修改。统计、安装、角色和健康状态均是模拟，不代表真实鉴权/Worker/对象存储已验证。
- 独立 Demo 不调用生产接口或修改线上数据；共享 UI 在生产模式通过真实 API 工作。

## 验证入口

- `pnpm typecheck`；`pnpm test`（包含快照恢复测试；测试数量及结果以本轮验证记录为准，早期106项不是当前总数）。
- `tests/framework-demo.browser.mjs`：完整UI闭环、所有页面、两种桌面宽度、图片加载与截图、真实API请求检查。
- `tests/framework-demo-faults.browser.mjs`：慢图、坏图重试、多标签页、写入失败与重置。
- 浏览器脚本使用独立 context，不接触用户浏览器数据；通过 `PLAYWRIGHT_MODULE` 指向可用 Playwright 模块URL、`DEMO_URL`指定演示服务、`CDP_URL`指定本机浏览器连接。
- 验证证据及逐页截图在 `output/framework-demo-2026-09-21/`；最终审核报告以该目录的 review.md 为准。
