# API 五任务并发实现与验收

## 2026-09-23 · API 换套图五任务并发

API 换套图全站最多同时执行5个任务，按任务而非账号计数，第6个及以后排队；空出名额后按原任务创建顺序准入。已准入任务在批次切换、退避和收图期间保留名额，整套终态后释放。已完成任务再次修改/重试重新排队，不能挤占在途任务；同任务在途追加修改不另占名额。
每任务仍最多10图并行，严格按10张分批；全站最多50张在途。API Worker部署池同步为5。重复派发和多进程竞争受数据库通道行锁约束。暂停与不确定调用的保守阻断、已返回结果安全收图、原重试及版本逻辑保留。Codex CLI调度不变。用户后续授权三项整改，已完成实现、隔离验证、独立审查及生产部署。

## 实施顺序

1. 在通道行锁内选择最多5个在途任务，优先保留已有任务，再准入排队任务；每个任务独立批次与10个图片租约。
2. 终态任务返工/重试标为排队，保留历史开始时间；明确领取后才标为运行，避免历史时间伪造名额。Worker池改5。
3. 验证6任务边界、50张上限、释放名额、退避、批次、旧任务修改、暂停/不确定及多进程竞争；回归现有API测试，独立代码审查。无前端改版或数据库迁移。
