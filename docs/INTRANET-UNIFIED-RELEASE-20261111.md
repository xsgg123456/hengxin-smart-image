# 内网统一 Git 版本发布

用户授权将 .245 内网运行代码统一到当前 Git，保留账号、数据和内网配置，验证国内、海外及 PPT/Codex；不操作旧公网。基准为 `6fe6271`，只补充现有账号服务的环境 UID 适配及本次发布工具，不增加产品功能。

1. 固定源码与前端构建清单；账号服务直接读取既有 `HX_OVERSEAS_WORKER_UID`，默认 999 保持旧部署兼容，内网沿用 1002。今早的 HTTP、PPT、沙箱、CLI 修复必须包含在源码清单中。
2. 复用现有依赖、账号目录、环境变量及所有数据挂载；在独立发布目录准备 Git 源码，8 个 Python 容器与 7 个原生服务统一使用该目录，前端使用对应构建。数据库无迁移，数据容器不重建。
3. 备份运行配置、排空在途任务后切换；健康或启动验证失败恢复原配置和代码入口。只有本机 .245 允许执行发布工具。
4. 核对运行进程源码摘要、前端实际响应、配置与数据保存情况，验证国内与海外页面/接口和真实 Codex 图片执行、PPT 读取。记录实际执行的范围；未测试分支不宣称全量通过。

源码一致指运行加载的应用代码与发布提交逐文件一致；环境配置、账号、数据以及保留供旧页面使用的历史静态资源不属于 Git 源码。运行依赖保持现有版本，避免无关升级。
