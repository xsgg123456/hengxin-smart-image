# 海外 Skill 独立存储与真实删除实施合同

用户已授权开发、测试、独立审查、中文 Git 提交、生产部署，以及最终真实回收多余安装版本。保留全部历史会话、上下文、附件、图片和工作文件；不调用收费模型。覆盖旧文件夹管理合同“删除仅移出目录并永久保留完整安装版本”的实现方式。

## 目标与边界

1. 技能实体按名称和内容校验值独立保存，发布版本只保存小型目录索引。上传相同内容直接复用；更新或删除 A 不复制其他技能。完整文件、空目录、原始字节、权限检查和下载一致性保留。
2. 删除必须真实清除该技能不再需要的中央实体、旧安装副本及对应已完成上传暂存；历史会话拥有的独立技能副本保留。删除响应只有在实际清理完成后才成功，并返回实际回收量。部分失败留持久恢复状态，支持重试，不报虚假成功。
3. 队列中、执行中、收取中、未确认退出等仍使用该技能的任务阻止删除，明确提示稍后重试；不强停任务。更新仍允许冻结中的旧任务读取原版本，不能切成新版本。
4. 旧会话读取优先核对本会话已有技能副本，必须与原冻结清单一致，不跨会话读取、不篡改原始 payload 或聊天内容。缺少副本时先从完整安装源补齐并校验，计入新增占用。已结束的非 Studio 任务同样保留所需独立执行资料。
5. 将当前中央存储切为独立实体后，旧发布索引可保留，但不永久保留全量实体副本。垃圾回收依据当前目录、在途引用和已验证历史副本，禁止仅按文件时间或“未开启”判断。
6. 正式目录对 API/worker 只读；publisher 受控写入。新增会话执行目录访问必须显式限定路径、业务和属主，不能把生产会话暴露进模型挂载或前端。

## 实施顺序与验收

1. 存储：新增独立对象存储辅助模块，兼容旧清单与新索引；安装、冻结、下载都核对同一内容。测试相同上传不增实体、更新 A 不复制 B、空目录与二进制保持、篡改拒绝。
2. 历史：调整执行准备与受控历史快照检查。真实临时文件测试删除中央旧包后原会话技能仍可读取，保留 session/附件/工作文件，跨会话及链接攻击拒绝。
3. 生命周期：发布事务、在途阻止、物理清理、上传暂存清理、幂等与崩溃恢复。测试第一次/最后一个技能删除、重复删除、权限/版本冲突、磁盘错误和并发提交；失败不能错误报告完成。
4. 前端：沿用当前确认框，说明历史会话资料保留、运行中不可删；成功显示真实释放量。类型、全前端测试、构建和正式组件浏览器验证。
5. 发布：独立两阶段审查及固定快照，中文提交；制品隐私检查、实际安装路径与身份测试；核对当前 API/publisher/native 基线，关闭接纳并排空，备份恢复验证后切换，保持国内服务。
6. 生产迁移回收：重算固定清单和引用，保存外部可恢复备份，核对所有相关历史副本后清旧安装实体，保持原索引可解析；对比历史记录、上下文及文件保留证据，核对当前技能下载/选择/准备和服务健康，报告同一统计范围的净回收量。

先前只读测算：安装库 6,856,118,272 字节，24 套版本、345 份包、25 种内容；当前八包 283,553,792 字节；33 个历史会话 35 组内容副本已齐，预计净回收约 6.57 GB。此值不是承诺或已回收量，执行前重新核算。真实模型续聊仍不调用、不宣称已验证。
## 生产核查补充（2026-11-06）

同一会话可以在不同发布索引中引用完全相同的技能内容。保留副本按内容去重，但磁盘冻结输入与数据库的核对必须保留每次任务的原始发布引用，不能先按内容去重后误判历史输入失配；真正没有归属的输入仍须阻止回收。
